diffy's nixos configuration files, written with love using [bundle](https://github.com/different-name/bundle-of-nix)!

every module in [`diffy/shared`](diffy/shared) is a toggle, [profiles](diffy/shared/profiles) flip them on in batches, and each [host](diffy/hosts) picks a profile plus whatever is specific to it
